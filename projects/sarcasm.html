Sarcasm Detection with Transformers

Short-text sarcasm classification using fine-tuned BERTweet models, training-stability techniques, and systematic evaluation.

BERTweetPyTorchHugging Face
Insert Picture

Overview

A transformer-based NLP project exploring sarcasm classification in short-form text. The experiments use BERTweet and compare model fine-tuning decisions against simpler baseline classifiers.

Methods

  • Fine-tuned BERTweet with PyTorch and Hugging Face Transformers.
  • Investigated weighted loss for class imbalance and gradient clipping for training stability.
  • Created a reproducible train/evaluate workflow with checkpoints, baseline comparisons, and ablations.

Results

Reported results: 85% macro-F1 and 0.90 ROC-AUC, with a roughly 20–30-point F1 improvement over baselines in the evaluated setup.

These figures come from my current CV. I would add a dataset description, experiment table, and full reproducibility notes before presenting this as a public benchmark.
