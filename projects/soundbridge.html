Overview

SoundBridge is a music discovery and similarity retrieval project that explores two approaches to representing audio: handcrafted signal-processing features and semantic embeddings learned by a pretrained CLAP model.

It supports both audio-to-audio and text-to-audio search. The prototype connects audio preprocessing, embedding generation, retrieval, and a user-facing interface.

What I built

  • Audio preprocessing pipeline with standardized 30-second, 22.05 kHz mono clips and librosa feature extraction.
  • Handcrafted audio-feature baseline with cosine similarity and 512-dimensional CLAP audio/text embeddings.
  • FastAPI backend, SQLite metadata and search-log layer, and a Streamlit interface.
  • Retrieval evaluation and automated REST API tests.

Dataset

The project uses a balanced 80-track subset of FMA Small, spanning eight genres. Audio files are not bundled in the public GitHub repository.
