SoundBridge

结合手工音频特征与跨模态 CLAP 嵌入的音乐相似度检索。

概述

SoundBridge 是一个音乐发现与相似度检索项目，探索两种音频表示方法：手工设计的信号处理特征，以及预训练 CLAP 模型学习得到的语义嵌入。

它同时支持以音频检索音频、以文本检索音频。原型整合了音频预处理、嵌入生成、检索与用户界面。

我实现的功能

  • 音频预处理流程：统一为 30 秒、22.05 kHz 的单声道片段，并使用 librosa 提取特征。
  • 构建基于余弦相似度的手工音频特征基线，并使用 512 维 CLAP 音频／文本嵌入。
  • 实现 FastAPI 后端、基于 SQLite 的元数据与搜索日志层，以及 Streamlit 界面。
  • 开展检索评估与自动化 REST API 测试。

数据集

项目使用 FMA Small 中一个类别均衡的 80 首曲目子集，涵盖八种音乐风格。公开 GitHub 仓库不包含音频文件。
