概述

Strategy.town 是一个支持实时多人交互的全栈游戏与社区博客平台，展示了我在机器学习研究之外构建接近生产环境的交互式 Web 应用的经验。

实现方式

  • 使用 React 和 TypeScript 构建前端，使用 Node.js / Express 提供服务。
  • 通过 Socket.IO 实时更新与私密对局邀请，实现实时交互。
  • 使用 Zod 模式实现端到端类型安全。
  • 使用 Vitest、Supertest 与内存 MongoDB 环境开展自动化测试。

部分成果

我目前的计算机科学简历中记录了这些成果：每日用户超过 50 人、所述测试套件的测试覆盖率达到 100%，以及界面刷新延迟降低 300 毫秒。

这是一个协作开发的 Web 平台；确认可公开分享的地址后，可以进一步补充源代码链接或截图。

研究重点

实时交互、Web 架构与类型化服务。
